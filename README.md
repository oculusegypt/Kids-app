# رحلة سارة التعليمية

تطبيق ويب عربي تفاعلي للأطفال، مبني بعناصر التصميم الموجودة في مجلد `Untitled (5)`.

## التشغيل

```bash
npm run dev
```

ثم افتح [http://localhost:4173](http://localhost:4173).

## خطة الشاشات

مراجع التصميم في `الشاشات/` لا تُستخدم كصور واجهة. تُركّب الشاشات من نصوص
وأزرار وبطاقات ورسوم وأيقونات مستقلة. راجع [SCREEN-PLAN.md](./SCREEN-PLAN.md)
لقائمة الشاشات الـ23، عناصر كل شاشة، فروع التنقل، وخطوات التنفيذ وحالات التحقق.

بدأ التنفيذ بالشاشة الرئيسية: عناصرها تُعرض منفصلة، والشاشات الأخرى تعرض حالة
«قيد التركيب» وروابط الفروع بدلًا من صور الشاشات المجمّعة. لم يكتمل تركيب بقية
الشاشات بعد.

عُزلت النسخ المطابقة بصريًا من الأصول المستخرجة؛ بقي الأرشيف الأصلي محفوظًا.
التطبيق لا يُعدّ مطابقًا حتى تُنفّذ كل شاشة من عناصر منفصلة وتُختبر روابطها.
