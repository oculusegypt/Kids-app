# رحلة سارة التعليمية

تطبيق ويب عربي تفاعلي للأطفال، مبني بعناصر التصميم الموجودة في مجلد `Untitled (5)`.

## التشغيل

```bash
npm run dev
```

ثم افتح [http://localhost:4173](http://localhost:4173).

## الشاشات والتفاعلات

- يبدأ التطبيق الآن من شاشات المرجع في `الشاشات/`، مع تطابق مرئي مباشر على مقاس الهاتف.
- التنقل الرئيسي يربط الرئيسية والكتب والأنشطة والإنجازات، مع روابط فرعية للحروف والقصص والرياضيات والألغاز والتلوين والتقارير والملف الشخصي.
- تفتح مناطق اللمس فوق الشاشات المرجعية الصفحات المناسبة، وتتيح صفحات الأنشطة فتح التمارين التفاعلية الحالية.
- مرسم التلوين التفاعلي يدعم اللمس والفأرة وتغيير الألوان وحجم الفرشاة وحفظ اللوحة.

تُحفظ النجوم والأنشطة المكتملة والإعدادات محليًا في المتصفح.
