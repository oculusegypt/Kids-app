# رحلة سارة التعليمية

تطبيق ويب عربي تفاعلي للأطفال، مبني بعناصر التصميم الموجودة في مجلد `Untitled (5)`.

## التشغيل

```bash
npm run dev
```

ثم افتح [http://localhost:4173](http://localhost:4173).

## الشاشات والتفاعلات

- الرئيسية ومؤشرات التقدّم.
- مكتبة الأنشطة مع تصفية بحسب المجال.
- أنشطة تفاعلية في الحروف والعدّ والأنماط والأشكال والقصص والألغاز والقراءة.
- مرسم يدعم اللمس والفأرة، وتغيير الألوان وحجم الفرشاة وحفظ اللوحة.
- الإنجازات والملف الشخصي وإعدادات الصوت.

تُحفظ النجوم والأنشطة المكتملة والإعدادات محليًا في المتصفح.
